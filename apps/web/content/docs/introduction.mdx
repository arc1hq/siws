# What is SIWS?

**Sign In With Solana (SIWS)** is a standard for authenticating users with their Solana wallets. It defines a human-readable message format and Ed25519 signature verification process that enables applications to verify wallet ownership without on-chain transactions.

SIWS follows the pattern established by [EIP-4361](https://eips.ethereum.org/EIPS/eip-4361) (Sign-In with Ethereum), providing a familiar and interoperable authentication flow for the Solana ecosystem.

## Key Features

- **Human-readable messages** -- Users see exactly what they're signing before approval
- **Ed25519 signatures** -- Native Solana signing, no on-chain transactions needed
- **Replay protection** -- Server-generated nonces prevent signature reuse
- **Domain binding** -- Messages are bound to the requesting origin
- **Expiration support** -- Messages can expire after a configurable window
- **Cluster awareness** -- Prevents cross-cluster replay attacks (`mainnet-beta`, `devnet`, `testnet`)

## Quick Example

```ts title="server.ts"
import { SiwsMessageBuilder, generateNonce, verifySignature } from '@siws/core'

// 1. Build a message for the user to sign
const message = new SiwsMessageBuilder()
  .domain('example.com')
  .address(walletAddress)
  .uri('https://example.com/auth')
  .nonce(generateNonce())
  .issuedAt(new Date())
  .cluster('mainnet-beta')
  .statement('Sign in to Example')
  .build()

// 2. Send message.toMessage() to the client for signing

// 3. Verify the signature
const result = await verifySignature(
  messageString,
  signature,
  walletAddress,
  { domain: 'example.com' }
)

if (result.success) {
  // Authenticated! result.data contains parsed message fields
}
```

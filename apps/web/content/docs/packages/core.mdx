Implements the [SIWS specification](/docs/specification) -- message construction, parsing, validation, and signature verification.

## SiwsMessage

Immutable representation of a SIWS message. Validates all fields on construction.

```ts
import { SiwsMessage } from '@siws/core'

// Create from fields
const message = new SiwsMessage({
  domain: 'example.com',
  address: '7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU',
  uri: 'https://example.com/auth',
  version: '1',
  nonce: 'k8sj2n4b',
  issuedAt: '2024-01-15T12:00:00Z',
  cluster: 'mainnet-beta',
  statement: 'Sign in to Example',
})

// Parse from string
const parsed = SiwsMessage.parse(rawMessageString)

// Serialize to string
const str = message.toMessage()

// Extract fields
const fields = message.toFields()
```

### Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `static parse(message: string)` | `SiwsMessage` | Parse and validate a raw message string (canonical form only) |
| `toMessage()` | `string` | Serialize to the canonical string format |
| `toFields()` | `SiwsMessageFields` | Extract fields as a plain object |

### Strict parsing

`parse()` only accepts a message in canonical form: the input must be byte-for-byte equal to `toMessage()` of the parsed result. It throws `PARSE_ERROR` for:

- CRLF line endings or a trailing newline
- fields out of order, duplicate fields (e.g. two `Nonce:` lines), unknown fields, or junk lines
- extra or missing blank lines, or a statement that looks like a field line (e.g. `URI: ...`)
- an empty `Resources:` section

One signed string therefore maps to exactly one set of fields. `verifySignature` applies the same rule to string input, so pass it the exact string the wallet signed.

## SiwsMessageBuilder

Fluent builder for constructing `SiwsMessage` instances. Accepts `Date` objects for timestamp fields.

```ts
import { SiwsMessageBuilder, generateNonce } from '@siws/core'

const message = new SiwsMessageBuilder()
  .domain('example.com')
  .address(walletAddress)
  .uri('https://example.com/auth')
  .nonce(generateNonce())
  .issuedAt(new Date())
  .expirationTime(new Date(Date.now() + 10 * 60 * 1000))
  .cluster('mainnet-beta')
  .statement('Sign in to Example')
  .addResource('https://example.com/api/profile')
  .build()
```

### Builder Methods

| Method | Parameter | Description |
|--------|-----------|-------------|
| `domain(domain)` | `string` | Requesting domain |
| `address(address)` | `string` | Solana wallet address |
| `uri(uri)` | `string` | Authentication URI |
| `nonce(nonce)` | `string` | Replay-protection nonce |
| `issuedAt(issuedAt)` | `string \| Date` | Message creation time |
| `statement(statement)` | `string` | Human-readable statement |
| `expirationTime(time)` | `string \| Date` | Message expiration |
| `notBefore(time)` | `string \| Date` | Earliest validity time |
| `requestId(id)` | `string` | Application-specific request ID |
| `cluster(cluster)` | `Cluster` | Solana cluster |
| `resources(resources)` | `string[]` | Resource URIs |
| `addResource(resource)` | `string` | Append a resource URI |
| `build()` | -- | Validate and return `SiwsMessage` |

## verifySignature

Verify a signature against a SIWS message.

```ts
import { verifySignature } from '@siws/core'

const result = await verifySignature(
  messageString,  // raw message string or SiwsMessage
  signature,      // Base58-encoded Ed25519 signature
  publicKey,      // optional -- must equal the address in the message
  {
    domain: 'example.com',  // domain check (omit = no domain binding)
    nonce: expectedNonce,    // nonce check (omit = no replay protection)
    time: new Date(),        // optional time override
  }
)

if (result.success) {
  console.log('Authenticated:', result.data.address)
} else {
  console.error('Failed:', result.error.code, result.error.message)
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `message` | `string \| SiwsMessage` | The message to verify |
| `signature` | `string` | Base58-encoded Ed25519 signature (64 bytes) |
| `publicKey` | `string?` | Base58-encoded public key, e.g. the address the client claims. If given, it must equal the message `address`, otherwise verification fails with `INVALID_ADDRESS`. Defaults to the message `address` |
| `options` | `VerificationOptions?` | Domain, nonce, and time checks |

The signature is always verified against the `address` in the message. `verifySignature` never throws; failures are returned as `{ success: false, error }`.

> **Warning:** `domain` and `nonce` are optional, but omitting `domain` disables domain binding (a signature made for another site is accepted) and omitting `nonce` disables replay protection. Always pass both on the server, using a server-issued, single-use nonce.

### VerificationResult

A discriminated union on `success`, so `if (result.success)` narrows `data` and the `else` branch narrows `error`:

```ts
type VerificationResult =
  | { success: true; data: SiwsMessageFields; error?: undefined }
  | { success: false; error: SiwsError; data?: undefined }
```

## generateNonce

Generate a cryptographically random Base58 nonce.

```ts
import { generateNonce } from '@siws/core'

const nonce = generateNonce()     // 16 characters (default)
const long = generateNonce(32)    // 32 characters
```

Uses `crypto.getRandomValues` with rejection sampling for uniform distribution across the Base58 alphabet.

## Types

### SiwsMessageFields

```ts
interface SiwsMessageFields {
  domain: string
  address: string
  uri: string
  version: string         // always '1'
  nonce: string
  issuedAt: string        // ISO 8601
  cluster: Cluster
  statement?: string
  expirationTime?: string // ISO 8601
  notBefore?: string      // ISO 8601
  requestId?: string
  resources?: string[]
}
```

### Cluster

```ts
type Cluster = 'mainnet-beta' | 'devnet' | 'testnet'
```

### SiwsError

```ts
class SiwsError extends Error {
  readonly code: SiwsErrorCode
  readonly expected?: string
  readonly received?: string
}
```

### SiwsErrorCode

All error codes:

| Code | When |
|------|------|
| `INVALID_DOMAIN` | Domain format validation fails |
| `INVALID_ADDRESS` | Not a Base58 string that decodes to a 32-byte key, or `publicKey` does not match the message address |
| `INVALID_URI` | URI format validation fails |
| `INVALID_VERSION` | Version is not `'1'` |
| `INVALID_NONCE` | Nonce too short or not alphanumeric |
| `INVALID_TIMESTAMP` | Not a valid UTC ISO 8601 datetime or not a real calendar date (e.g. Feb 30) |
| `INVALID_STATEMENT` | Contains newlines or non-printable chars |
| `INVALID_CLUSTER` | Not a recognized cluster value |
| `INVALID_RESOURCE` | Resource URI format invalid |
| `INVALID_SIGNATURE` | Signature is not valid Base58 or wrong length |
| `INVALID_REQUEST_ID` | Contains non-printable characters |
| `MESSAGE_EXPIRED` | Current time is at or after `expirationTime` |
| `MESSAGE_NOT_YET_VALID` | Current time precedes `notBefore` |
| `DOMAIN_MISMATCH` | Message domain doesn't match expected |
| `NONCE_MISMATCH` | Message nonce doesn't match expected |
| `PARSE_ERROR` | Message string cannot be parsed or is not in canonical form |
| `MISSING_REQUIRED_FIELD` | A required field is missing |
| `SIGNATURE_VERIFICATION_FAILED` | Ed25519 verification returned false |

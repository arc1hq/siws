## Install @siws/core

`@siws/core` is a core library for building and verifying SIWS messages.

<Installation package="@siws/core" className="mt-4" />

**Requirements:** Node.js >= 18. No native dependencies -- uses `@noble/curves` and `bs58`.

### Usage

```ts
import { SiwsMessageBuilder, generateNonce, verifySignature } from '@siws/core'

// Build a message
const message = new SiwsMessageBuilder()
  .domain('example.com')
  .address('7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU')
  .uri('https://example.com/auth')
  .nonce(generateNonce())
  .issuedAt(new Date())
  .cluster('mainnet-beta')
  .build()

const messageString = message.toMessage()

// Verify a signature
const result = await verifySignature(messageString, signature)
```

## Install @siws/better-auth

A [better-auth](https://www.better-auth.com/) plugin with automatic nonce management, user creation, and session handling.

<Installation package="@siws/better-auth" className="mt-4" />

**Peer dependency:** `better-auth` >= 1.0.0

### Setup

**Server:**

```ts title="auth.ts"
import { betterAuth } from 'better-auth'
import { siws } from '@siws/better-auth'

export const auth = betterAuth({
  plugins: [
    siws({
      statement: 'Sign in to MyApp',
    }),
  ],
})
```

**Client:**

```ts title="auth-client.ts"
import { createAuthClient } from 'better-auth/client'
import { siwsClient } from '@siws/better-auth/client'

export const auth = createAuthClient({
  plugins: [siwsClient()],
})

// Get nonce and message
const { nonce, message } = await auth.siws.getNonce({
  address: walletAddress,
  cluster: 'mainnet-beta',
})

// Sign with wallet and verify
const signature = await wallet.signMessage(new TextEncoder().encode(message))
const result = await auth.siws.verify({
  message,
  signature: bs58.encode(signature),
  address: walletAddress,
})
```

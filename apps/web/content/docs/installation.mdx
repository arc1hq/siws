## Install @siws/core

`@siws/core` is a core library for building and verifying SIWS messages.

<Installation package="@siws/core" className="mt-4" />

**Requirements:** Node.js >= 20. No native dependencies -- uses `@noble/curves` and `@scure/base`.

### Usage

```ts
import { SiwsMessageBuilder, generateNonce, verifySignature } from '@siws/core'

// Build a message
const message = new SiwsMessageBuilder()
  .domain('example.com')
  .address('7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU')
  .uri('https://example.com/auth')
  .nonce(generateNonce())
  .issuedAt(new Date())
  .cluster('mainnet-beta')
  .build()

const messageString = message.toMessage()

// Verify the signature. Always pass `domain` and the nonce you issued:
// without them there is no domain binding or replay protection.
const result = await verifySignature(messageString, signature, undefined, {
  domain: 'example.com',
  nonce: storedNonce,
})

if (result.success) {
  console.log('Signed in as', result.data.address)
} else {
  console.error(result.error.code, result.error.message)
}
```

## Install @siws/better-auth

A [better-auth](https://www.better-auth.com/) plugin with automatic nonce management, user creation, and session handling.

<Installation package="@siws/better-auth" className="mt-4" />

**Peer dependencies:** `better-auth` and `@better-auth/core` `>=1.7.7 <2`. After adding the plugin, run your better-auth migrations to create the `solanaAddress` table.

### Setup

**Server:**

```ts title="auth.ts"
import { betterAuth } from 'better-auth'
import { siws } from '@siws/better-auth'

export const auth = betterAuth({
  // The SIWS domain and URI come from baseURL (or BETTER_AUTH_URL, or the
  // plugin's `domain`/`uri` options), never from request headers.
  baseURL: 'https://example.com',
  plugins: [
    siws({
      statement: 'Sign in to MyApp',
    }),
  ],
})
```

**Client:**

```ts title="auth-client.ts"
import { createAuthClient } from 'better-auth/client'
import { siwsClient } from '@siws/better-auth/client'

export const auth = createAuthClient({
  plugins: [siwsClient()],
})

// Get nonce and message
const { data: nonceData, error: nonceError } = await auth.siws.getNonce({
  address: walletAddress,
  cluster: 'mainnet-beta',
})
if (nonceError || !nonceData) throw new Error(nonceError?.message)

// Sign the exact message string (don't modify it) and verify
const { message } = nonceData
const signature = await wallet.signMessage(new TextEncoder().encode(message))
const { data, error } = await auth.siws.verify({
  message,
  signature: bs58.encode(signature),
  address: walletAddress,
  cluster: 'mainnet-beta',
})

if (error) {
  console.error(error.code, error.message) // e.g. INVALID_OR_EXPIRED_NONCE
} else {
  console.log('Signed in as', data?.user.address)
}
```
